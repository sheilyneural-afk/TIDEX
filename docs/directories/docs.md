# `docs/`

Documentación del proyecto. Punto de entrada: [INDEX.md](../INDEX.md).

**Ubicación:** `docs/`  
**Relacionado:** [INDEX](../INDEX.md)

## Estructura

| Árbol | Contenido |
|-------|-----------|
| `INDEX.md` | Mapa localizable |
| `ARCHITECTURE.md`, `SYSTEM_STATUS.md`, `IMPLEMENTATION.md`, `QUALITY_AND_TESTING.md` | Maestros |
| `directories/` | Un doc rico por directorio/dominio |
| `systems/` | Flujos transversales |
| `FORMULAS_*` | Catálogo algorítmico |
| `AUDITORIA_*`, `CONTRA_*` | Auditorías |
| `design/` | Notas de diseño |

## Estándar de calidad de un doc

Debe responder: qué es, por qué, flujo, invariantes, archivos con rol, relaciones. Un índice de filenames **no** basta.
